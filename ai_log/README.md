# Journal d'usage de l'IA (exigence R3)

Ce dossier contient :

- `conversations/` : l'export brut de chaque conversation avec un outil d'IA (lien de partage enregistré
  dans un fichier `.md`, ou export texte / PDF de la conversation) ;
- une note par séance de travail, nommée `AAAA-MM-JJ_seance-NN.md`, qui dit pour chaque morceau produit :
  - **gardé tel quel** ;
  - **corrigé à la main** : quoi, et pourquoi ;
  - **prompt ou pseudo-code réécrit** : quelle ligne, et pourquoi.

Règle suivie : aucune clé d'API, aucun mot de passe, aucune donnée personnelle dans un prompt ni dans ce dossier.
